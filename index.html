🤖 零後端建站 SOP 與 GitHub Actions 自動排程

本架構採用「零後端靜態網站 + Python 自動化資料管線 + GitHub Actions 定時部署」，每日於台灣時間 06:30（美股收盤後）、16:00 / 18:00（台股盤後與估值公布後）自動執行 scripts/fetch_stocks.py 並重新部署 GitHub Pages。

Step 1｜定義標的與金主/美日合作圖譜：編輯 config/stocks_config.json，填入代號、capital_backers（上市櫃金主與持股%）及 intl_coop（美日合作與 MOU）。
Step 2｜Python 管線抓價算指標：執行 python scripts/fetch_stocks.py，自動向 TWSE、TPEx、Yahoo Finance 與 Google News RSS 抓取行情/財報/新聞，輸出 data/stocks.json 與 data/stocks.js。
Step 3｜推送 GitHub 並開啟 Pages：建立 Repo 推送至 main 分支，至 Settings → Pages 將 Source 設為 GitHub Actions，並開啟 Workflow 讀寫權限（Read and write permissions）。
Step 4｜全自動免維運上線：由 .github/workflows/update-data.yml 每日三時段自動抓資料、Commit 並部署上線（亦可點 Run workflow 手動觸發）。
